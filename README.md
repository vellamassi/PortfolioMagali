# Portfolio Magali
Redesign of Magali's portfolio page, built with React, Vite, and TypeScript, with Directus as the headless CMS. I built it to learn React on a real project.

## Tech stack

- React
- Vite
- TypeScript
- Directus (headless CMS)
- PostgreSQL (database for Directus)
